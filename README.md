# 🧮 CalPy

CalPy is a simple web-based calculator application built using **Python and Flask**. It provides an easy-to-use interface for performing basic mathematical calculations through a web browser.

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- Editable calculator input
- Simple and clean user interface
- Web-based application

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS

## 📁 Project Structure

```text
calpy/
├── app.py
├── requirements.txt
├── .gitignore
└── templates/
    └── index.html
```

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Jishnuprazval/calpy
```

### 2. Move into the project directory

```bash
cd calpy
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

Then open the local address displayed in the terminal in your web browser.
